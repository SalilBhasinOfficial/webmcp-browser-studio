# Demo video script — target 2:25

## 0:00–0:20 — Problem

“Agents can click through websites, but those interactions are brittle and hard to audit. Bridge Studio turns visible workflows into narrow, typed capabilities that a person controls.”

## 0:20–0:50 — Discover and review

Open Voyager Stays and click **Inspect page**. Open `search_stays`. Show its required inputs and read-only status, tick the review checkbox, and approve it.

“The tool is not available until I review its contract. This one reads inventory and updates our shared results; it cannot book anything.”

## 0:50–1:20 — Agent execution

Ask the agent: “Search Lisbon for two guests, October 12 to October 16.” Show the page and trace update.

“The agent calls a semantic operation instead of guessing through five fields. I see the result in the same interface and the execution is recorded.”

## 1:20–1:55 — Consequential boundary

Navigate to `demo://civic-desk`. Approve `prepare_permit_draft`, emphasizing **changes page state**. Ask the agent to prepare a street-event draft. Show the visible “Review, do not submit” state.

“State-changing tools require approval. The agent can prepare the work, but this contract cannot submit it.”

## 1:55–2:15 — Security

Navigate to an external URL and show the boundary banner.

“Bridge Studio does not bypass origins, inspect credentials, or claim native support where none exists. External content stays isolated.”

## 2:15–2:25 — Close

“Bridge Studio is a path from browser actuation to an agent-native web: typed, visible, and governed by people.”
